Reachy Mini Wireless · CM4 · daemon 1.10 · Strands

A robot that moves when it talks.

TINY is a Reachy Mini with a Strands agent inside. Four microphones that know where you are, a camera that finds your face, a six-axis head, two antennas and 81 recorded emotions — and a model that fires them while it speaks, not after.

one realtime session · tools fire during speech

It moves while it speaks. Not after.

The voice persona is one Strands BidiAgent: microphone in, speech out, tool calls inside the same response. The gesture lands on the word, face-tracking lets go of the head only while it talks, and you can interrupt it.

  1. tiny.py:266 · the voice rules- Move WHILE you speak — gestures are simultaneous, never before/after.
  2. tools/reachy_expression.py:89Call it alongside speaking, just like neon fires arm gestures.
  3. tools/head_tracking.py:114 · SpeakingHandoffwhile the model streams speech audio → tracking hold "speaking" (weight 0.0 …); on response complete / interruption → release (weight 1.0) after a short playback tail.
  4. tools/xmos_audio.py:9 · XVF3800PP_NLATTENONOFF=0 suppression 17 dB → 4 dB; barge-in confirmed by the owner.

18 bodies · 9 motors · one twin.xml

Nine motors. One face.

The dashboard's digital twin is the robot's own MuJoCo model, so this is not an illustration — it is the geometry the daemon solves against, split by body group.

  1. antennas two hinges, right_antenna · left_antenna — the fastest tell of a mood (curious1 throws one to 77° and the other to −85°)
  2. head body xl_330 with the camera_optical site — the face-finding camera; six degrees of freedom: roll, pitch, yaw and a little x y z
  3. Stewart platform six stewart_1…6 hinges on six rods with passive_1…6 ball joints — the head has no neck motor; six arms hold it up and tilt it together
  4. body yaw_body ±160° on the 3D-printed foot; inside the shell: a Raspberry Pi CM4, four microphones and the speaker

run it yourself · robot or MuJoCo sim

Six lines to a robot that talks back.

Bring a Reachy Mini and a Bedrock or OpenAI key — or no robot at all: make sim spawns a headless MuJoCo daemon.

Quickstart Showcase GitHub

git clone https://github.com/cagataycali/tiny-the-reachy.git
cd tiny-the-reachy
cp .env.example .env && $EDITOR .env   # your keys
make venv                              # .venv + deps
make run                               # REPL → the daemon
make sim                               # …or no robot at all
