# Original documentation artwork

The Reachy companion illustration is inline SVG in
`docs/overrides/partials/companion.html`, drawn for this project from simple
geometric paths. No photographs, model files, external illustrations or
third-party artwork were copied. Distributed under the repository's MIT license.

The three illustrated poses teach head tilt, antenna expression and neutral
pose. They are not recorded-emotion playback, an accurate kinematic simulation,
a live camera feed or a connection to a robot. The accompanying code labels
refer to `tools/reachy_motion.py`; clicking never executes them.
